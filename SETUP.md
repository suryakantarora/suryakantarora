# Profile README — how it works

The profile is a stack of animated SVG cards in `assets/`, generated from live GitHub data by `scripts/generate.mjs`. GitHub READMEs don't allow CSS or JavaScript, so all motion lives inside the SVGs.

## Layout

```text
.github/workflows/
  profile-cards.yml   daily: regenerates assets/*.svg, the Featured builds table and the 3D skyline
  snake.yml           daily: contribution snake, published to the `output` branch
assets/               generated cards — don't edit by hand, they are overwritten
profile-3d-contrib/   generated by the workflow (appears after its first run)
scripts/
  generate.mjs        card generator (Node 20+, no dependencies)
  icons.json          tech icon paths (from Simple Icons)
README.md
```

## One-time setup

1. Push to `main`.
2. **Settings → Actions → General → Workflow permissions** → select **Read and write permissions**.
3. **Actions → Refresh profile cards → Run workflow** (it also runs on its own after a push that touches `scripts/`). The first run creates `profile-3d-contrib/`; until then the "Contribution skyline" image is missing.

## Changing the content

Everything editable is in the `PROFILE` object at the top of `scripts/generate.mjs`: name, typing lines, positioning pills, tagline, years of experience, depth and focus areas, and the tools. Numbers (repos, stars), the ID-badge photo, location and company come from your public GitHub profile.

The photo on the top card is `assets/coder.jpg` (560×560 JPEG, embedded into `intro.svg`). To change it, replace that file and regenerate — the glow, earcup ring, cursor and lens-glint overlays are positioned for the current picture (the `at(x, y)` source-pixel coordinates in `intro()`), so adjust or remove them for a different one. The details beside it come from `PROFILE` and your public GitHub profile (company, location).

Preview locally:

```sh
node scripts/generate.mjs
open assets/hero.svg
```

To add a tool, add its Simple Icons path to `scripts/icons.json` under its slug and a `[slug, label, colour]` entry to `PROFILE.coreTools` (the seven large tiles) or `PROFILE.moreTools` (small pills, five per row).

The "Also on GitHub" table in `README.md` is rewritten between the `<!-- FEATURED:START -->` and `<!-- FEATURED:END -->` markers; it lists your non-fork repositories by stars and skips any repo named in `PROFILE.hiddenRepos`.
